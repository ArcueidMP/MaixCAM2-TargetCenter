1 · 总体架构（双轨对照）

两条轨实现同一个视觉子任务：由 A4 靶纸四周 1.8cm 黑胶带矩形的几何，反算靶心像素坐标 (u,v)（B 轨另给像素↔毫米）。技术路线根本不同，可互为对照。

维度A 轨（根，DeepSeek）B 轨（maixcam2_rect_center，GPT）
分割灰度固定/Otsu 阈值二值化 + 形态学，扫描表择优并锁定Canny + approxPolyDP；失锁时 Otsu/多档暗阈值掩膜兜底
候选ring（深色环）/ paper（亮面矩形）双族 + 结构打分选优内/外凸四边形配对 + 四边灰度剖面校验
中心解算对角线交点（射影不变量，不解单应）+ 角点亚像素精修显式 8×8 单应，正视面圆心逆映射回原图
尺度A4 边长反算 px_per_cm（外沿/内沿两口径）像素↔毫米单应（homography_8x8/project_points，mm→px 已写）
时序抗抖跟踪：常数速度卡尔曼 + 新息门限 + 尺度/清晰度一致性窄带四边跟踪 + CENTER_ALPHA 一阶低通（显示口径）
下游输出 (u,v) + px_per_cm（串口默认关）激光偏差 + 双轴 ZDT 云台闭环 + 开环标定 + 上电自检

2 · A 轨视觉模块功能

2.1 geometry.py — 纯 NumPy 几何层 不依赖 cv2/maix

对应需求流程 ③④⑤⑥，并承担"退化姿态兜底"与"合法性裁判"。

功能实现要点
③ 取四顶点extreme_cornersx/y 极值四顶点；轴对齐时退化，由下一级兜底
④ 排序 [TL,TR,BR,BL]order_corners / order_corners_by_sumdiff / _best_quad质心极角排序（避免 x±y 在旋转 45° 时并列退化）；多方向极值 + 最大凸包面积
退化识别_too_thin / quad_fit_error轮廓点到四边形边界平均距离当裁判，自动在极值法/多方向法间择优
③④ 组合extract_ordered_corners三级兜底 + 裁判，返回 (角点, 方法名)
⑤ 求对角线交点diagonal_intersection / seg_intersect射影不变量：直线映射为直线、交点映射为交点 ⇒ 交点是精确靶心，免解 H
合法性is_valid_quad / opp_side_convergence面积下限 + 凸性 + 对边比 + 长宽比 + 对边收敛自洽性（挡"凸/面积正常但中心偏 20px"的假四边形）
⑥ 尺度estimate_scale / scale_quadA4 边长反算 px_per_cm；支持外沿(21×29.7)/内沿(17.4×26.1)
⑦ One EuroOneEuroFilter低延迟滤波，现仅用于尺度通道（中心改用卡尔曼）

2.2 detector.py — OpenCV 主流程 A 轨核心

  • ① 二值化：binarize（固定/Otsu）、_morph（常规核 / 精细核两档，远距离救细环）、_mask_specs（"锁定值优先 + 固定/Otsu + 扫描表"的掩膜规格表）、_masks（生成器 + 每帧预算 + 游标轮转，命中即 break 真省事）。
  • ② 候选 + 结构打分：contour_features 提取 ring/paper 两族，三趟走（boundary_estimate 判碎渣 → _survivor_contours 连通域预筛 → _top_contours 截断）；score_candidate 按"外沿近矩形 / 内孔占比像环 / 环厚像 1.8cm 胶带 / 长宽比像 A4 / 实际灰度对比度"打分。
  • 灰度探针：_patch_mean（孔内亮面）、_band_gray（带向探针）、ring_thickness_px（按目标尺度自适应步长，远距离不跨过细胶带）。
  • 候选选择：select_frame_contour（结构分选优 + 族迟滞 KIND_BONUS 防 ring/paper 逐帧乱切；largest 仅作对照/兜底）。
  • ③④⑤ 解算：_quad_from_pts（extreme → sumdiff → hull+approxPolyDP 三级）、refine_corners_subpixel（四边 fitLine 求交，压角点量化抖动到亚像素）。
  • 主流程 process/_solve：整幅清晰度（Laplacian 方差）→ 帧间 ROI 跟踪 → 缩小图粗定位（WORK_SCALE）→ 全分辨率升级（force_sweep + 掩膜预算）→ 粗定位框内全分辨率精算 → 尺度 → 抗抖跟踪 → coast 短时外推。
性能治理：boundary_estimate(0.3ms) 预判 + 连通域预筛 + 掩膜预算，专治"某输入下复杂度爆炸"（掩膜 2 万条轮廓 → findContours 190ms）导致的 0.1fps。触发阈值 FRAG_BOUNDARY_EST=13000 为两路径实测交叉点。"干净掩膜走原路径、零行为变化"是设计约束。

2.3 tracker.py — 抗抖跟踪器 A 轨亮点

  • _CV1D：单轴常数速度卡尔曼(位置+速度)，手写 2×2 协方差免矩阵开销；update 带 dv_max 速度修正上限（防坏点把速度带飞）。
  • TargetTracker.update 四重机制：
    1. 自适应过程噪声 q：由"新息²/meas_var − 1"的机动倍率经对数映射到 [q_min,q_max]，静止重平滑、晃动跟手（判据必须扣掉测量噪声，否则滤波器追噪声）。
    2. 新息门限（硬跳变）：gate=max(ABS, K·近期新息尺度)，连续拒信时主动放开防级联锁死。
    3. 尺寸/尺度一致性：框尺寸、px_per_cm 突变超限即判误锁。
    4. 清晰度自适应：运动模糊帧放大测量噪声 r，更依赖预测。
  • coast：本帧完全没检出时用预测值顶 ≤TRACK_MAX_COAST 帧。
  • 核心结论（已实测证伪旧做法）：抖动位移是必须跟踪的真实运动，"一刀切低通"会拖出系统性偏移（One Euro static 均值 8.06px / 最大 27px，原始解算仅 0.10/0.39px）。

2.4 overlay.py — 可视化 零逐帧分配

预分配灰度/画布缓冲复用；绘制板框(绿)、对角线(蓝)、四顶点(TL/TR/BR/BL 黄)、靶心十字(红)、中心/尺度/stage 文本与 fps。

3 · B 轨视觉模块功能

3.1 vision/rectangle_center.py — 黑框识别与中心追踪 B 轨核心

  • 几何求解：_homography（显式 8×8 方程 + 坐标归一化提高稳定性）、project_points / inverse_map_points、standard_circle（72 点圆）、_order_quad。
  • 四边稀疏验证 _verify：每边 3 点黑带 + 2 点内侧亮面采样，不生成整幅 warp；判据含覆盖率、暗/亮比、对比度中位数；背景允许为黑（不强制外侧白），普通纸边与实心黑块会失败。
  • 窄带精修 _refine：当前帧四边灰度窄带 → 有向边缘跳变（近预测边缘优先，避捕获印刷圆）→ fitLine → 四角交点。
  • 候选生成 _candidate_quads：轮廓树孔/环关系替代两两组合；亮面孔优先。
  • 搜索 _search：缩小图多阈值（锁定值优先 + Otsu + DARK_THRESHOLDS）→ Canny 兜底 → _line_search 长线段拼四边（透明膜反光切断黑环时的恢复，默认 ENABLE_LINE_RECOVERY=False）。
  • 主入口 process：track → roi_search → full_search 三级；中心 = 正视面圆心 (w/2,h/2) 直接映射（非圆周平均），CENTER_ALPHA 一阶低通；输出含 raw_u/raw_v、circle_points、stage、outer_inferred 等。
  • draw_result：缩放后描边，屏幕文字下移避开激光面板。

3.2 vision/laser_spot.py — 激光光斑读数

  • LaserSpotDetector：标称位置邻域 LASER_ROI_RADIUS 内找最亮点，亚像素质心；限频（LASER_INTERVAL_S，未更新帧沿用上次）、跳变门限（防误检）、背景 1/4 子采样中位数、面积上下限挡高光/噪点。
  • 两种取位：fixed（默认，写死常量零检测）/ detect（自校准）。
  • deviation(laser, result, use_raw)：dx=靶心−光斑（正=靶心在光斑右/下），与云台"误差为正发 CCW"同符号；闭环必须 use_raw=True。
  • draw_laser_overlay：左上角面板 + 光斑圆叉 + 到靶心连线。

3.3 云台链路与控制（非视觉，但与视觉闭环直连）

模块功能

3.4 target_api.py — 对外 API 门面 跨小问复用

  • Result（dict 子类）：res["u"] 与 res.u 双写法，bool(res)==res.valid。
  • API ① detect_black_frame(frame)：无状态，每帧全图搜索，适合"取一次框"。
  • API ② CenterTracker / track_center / reset：有状态窄带跟踪 + 失锁重捕获；with_laser=True 额外带 laser_u/v、dx/dy。
  • API ③ AimLoop：追踪 → 偏差 → 发脉冲的完整闭环（会驱动电机；无电机时只出视觉结果）。
  • 辅助：to_gray（numpy / MaixPy image → 灰度）、load_config(**overrides)（不改磁盘造覆盖配置）；顶层不 import maix，PC 可离线跑。

7 · 两轨互补与差异

  • 中心解算的独立性：A 轨用"对角线交点"（不用单应，四角准即精确）；B 轨用"显式 8×8 单应 + 72 点圆"。两条数学路径互不依赖，可作为交叉验证。
  • 成熟度分布：A 轨在跟踪/抗抖/性能治理上更成熟；B 轨在几何/毫米单应/激光+云台闭环/对外 API 上更完整。工程上"补短板去另一轨抄已验证结论"。
  • 同一现象的不同解释：A 轨"车一晃中心就偏"= 滤波器跟不动（需卡尔曼）；B 轨把该问题落在 CENTER_ALPHA 平滑滞后 ≈28ms，并要求闭环必须用 raw_u/raw_v（A 轨用卡尔曼解耦）。

8 · 风险与待办

v3 基线特有风险（上板前务必处理）
  • 轴映射/方向是 v3 旧值：U1_DEV=/dev/ttyS1=yaw、U2_DEV=/dev/ttyS2=pitch，DIR_SIGN_YAW/PITCH=+1/+1、PULSE_PER_PX=3.67 均为占位/未经 v8 实测校正。这与"实测 ttyS0=pitch、ttyS2=yaw"的结论相反，上板前必须重新跑开环标定并核对接线，否则可能 yaw 不动或反向跑飞。
  • ACC_DEFAULT=0（无曲线加减速，瞬时启停，卡顿根源）；v3 无上电自检优先/帧率计量修复。
  • 工具陷阱：tools/apply_gimbal_track_patch.py 与 tools/git_round.py 是 v9+ 专用，对 v3 代码会误报/挡提交，勿运行。
  • B 轨 LENS_CORR=True（未调参的镜头畸变校正）在 v3 下开启，v19 才改为关闭；若上板见画面畸变需注意。
  • A 轨串口默认 ENABLE_UART=False；云台闭环能力在 B 轨。
  • B 轨 ENABLE_LINE_RECOVERY=False、ENABLE_SCAN=False、CALIBRATE_AXIS="" 均为默认关闭的安全态。
