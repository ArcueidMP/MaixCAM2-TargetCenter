## 2. 识别逻辑（核心：`A4RectangleDetector`）

目标：在画面中找到**靶纸上的矩形（内黑框）**，解算其**几何中心 = 靶心**，并换算成「靶心相对激光中心的像素偏移」发给 STM32。

### 2.1 单帧处理流水线

```
取帧 → flip(-1) 翻转 → 鱼眼去畸变(remap)
     → 灰度 → bilateralFilter(9,75,75) 双边保边去噪
     → Canny(50,150) 边缘
     → findContours(RETR_TREE, CHAIN_APPROX_SIMPLE)
     → 逐轮廓筛选 → 取最小面积的合格矩形
     → 透视变换生成 171×260 正视图 → 正视图中心反投影回原图 = 靶心
     → 与「激光中心」求差 → 串口发送
```

### 2.2 四边形筛选规则（三道门槛）

1. **面积**：`2000 ≤ area ≤ 80000`（像素）
2. **直角检查** `_is_rectangle`：`approxPolyDP(0.1×周长)` 后必须正好 4 个角点；对四个内角用向量点积求 `cosθ`，要求每个角 **≥ 70°** 才通过。
3. **长宽比检查** `_check_aspect_ratio`：相邻两边长比要接近 A4 比例 `26.0/17.1 = 1.520`，容差 `±0.4`，即允许比例落在 **[0.91, 2.13]** 区间。

> **关键技巧**：多个候选都合格时，代码**优先选面积最小的那个**（注释：「更可能是内矩形」）。因为靶纸是「回」字形多层框，取内框中心更接近真实靶心。

### 2.3 靶心解算（本题最有价值的一步）

不是简单取外接矩形中心，而是：

1. `_order_points` 把 4 角点排序为（左上、右上、右下、左下）；
2. `getPerspectiveTransform` 把该四边形**透视矫正**成 171×260 的正面俯视图（与 A4 等比），得到正视图；
3. 在正视图里取几何中心 `(85, 130)`，再用**逆透视矩阵** `cv2.perspectiveTransform` 把它**映射回原图** → 得到靶心在原图中的真实像素坐标 `rect_center`。

这样即使靶纸被斜视/透视形变，中心也稳定，且**中心只依赖 4 个角点**，比质心对噪声更鲁棒。

### 2.4 「激光中心」是拟合出来的，不是识别的

代码里的"激光中心"（黄点）**并没有实时检测激光光斑**，而是人为建模：

```python
if detector.detected_area == 0:
    laser_center = (330, 251)                       # 无目标时的缺省值
else:
    width_center = int(area*area*(-1.928e-09) + area*0.0004398 + 318.7)  # area 的二次拟合
    laser_center = (width_center, 251)              # y 恒为 251
```

用**靶纸面积**（≈距离代理量）去拟合激光在画面上的落点 x，用来补偿「摄像头与激光笔不同轴」带来的**视差**：目标越近（面积越大）→ 激光落点 x 越大。偏移量 = `rect_center - laser_center`。

### 2.5 串口协议

```python
data = f"@[{rect_center[0]},{rect_center[1]}];[{laser_center[0]},{laser_center[1]}]%\r\n"
```

仅当检测到矩形时发送。内容为：`[靶心x,靶心y];[激光x,激光y]`。

## 3. STM32 侧如何消费视觉结果

1. `entry.c`：`HAL_UART_RxCpltCallback` 逐字节状态机收包（`@`→数据→`%`），经 FreeRTOS 队列 `xQueueSendFromISR` 投递。
2. `dataRec.c` → `Position_DataRead()`：手写可变参数解析（**只解析整数**，以 `,`/空格/`]` 为分隔，不支持小数点），写入：
   - `targetPosition.x/y = 靶心像素坐标`
   - `nowPosition.x/y = 激光中心像素坐标`
3. `control.c` → `yunTaiVelocityControl()`：速度环 **PD** 控制（Kp=0.532, Ki=0, Kd=1.49），误差 = `target − now`（即像素偏移量），输出步进电机速度；并叠加两项前馈：
   - `speedx += myIMU.w[2] * 2.4f` → **反自旋**（陀螺仪角速度补偿）
   - `speedx += SpeedInverse * 95.7f` → **全局补偿**（小车行进角速度前馈）
4. `control.c` → `detectionAiming()`：当 `|Δx|≤3 且 |Δy|≤3` 像素判定瞄准完成 → `yunTaiQuestion.c` 的 `aimToDot()` 触发打点 `Dot(1)`。

## 5. 评价：亮点与隐患

### 亮点
- **纯几何方案、轻量实时**：树莓派 3B 即可跑，无需 GPU/模型。
- **透视变换 + 中心反投影**解靶心，思路干净、抗透视形变。
- 「取最小内框」巧妙解决多层嵌套框。
- 鱼眼去畸变 + 视差拟合 + IMU 反自旋 + 行进前馈，工程闭环完整，是拿国一的关键。

### 隐患 / 可改进
1. **直角阈值 70° 太宽松**（真实直角应≈90°），配合 **长宽比容差 ±0.4（[0.91,2.13]）极宽**，容易把桌面、纸箱等矩形物误检为靶纸。
2. **激光中心用面积二次拟合 + y 恒为 251**，物理意义弱、泛化差；换相机/镜头/距离必须重标定。更稳的做法是直接检测激光光斑（颜色/亮度阈值 + 质心）。
3. 检测不到时**不做跟踪外推**（`last_center` 直接置 None），运动中丢靶会直接失去目标。
4. 串口 `ser.write` 阻塞、无校验/无重发；`Position_DataRead` 不能解析小数。
5. 大量魔法数字硬编码（阈值、系数），换场地要重调。
6. 使用 `cv2.imshow` 可视化窗口，实际比赛需改为无头运行。
