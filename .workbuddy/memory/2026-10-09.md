## 10-09 第四轮：供电与电流口径（用户用可调电源，问两台电机分多少电流）

**事实（官方 Rev1.3 + 多源核实）**：
- 驱动器供电 **7–32V，官方推荐 24V**（欠压提示 `Waiting V+ Power`）；`11.8V≈12V` 可用但高速扭矩小。
- 驱动器侧电流：`Ma`（开环工作电流，默认 1000mA）、`Ma_Limit`（FOC 闭环堵转最大电流，默认 3000mA）。
  42 步进常见额定相电流 0.4/0.8/1.2/1.5/1.7/2.0A（按机身 40/48/60mm+）。云台轻载可设 ~1000mA。
- **两个层面别混**：驱动器 `Ma_Limit` = 单台**相电流**；可调电源限流 = 两台之和的**母线电流上限**。
  母线电流通常远小于相电流（FOC 轻载单台约 0.2–0.6A@24V）。
- 可调电源限流建议 **≥1.5–2.0A**；若被设在 0.3A，两台同时动会被拉进 CC、母线塌陷 → 欠压 → 更不动。
  判据：**CV 灯亮/电压稳 = 够；CC 灯亮/电压掉 = 调大**；电机壳 >70°C 降 `Ma_Limit`。

**本轮改动（文档类，无源码行为改动，未动 BUILD_ID）**：
- `README.md` 驱动器菜单表补 `Ma_Limit` / `Ma` 两行；新增「供电与电流（可调电源怎么设）」小节
  （电压建议 24V、两个电流层面的区别、限流 ≥1.5–2A、CV/CC 判据）。

## 23:25 ★ 修正轴映射（实测接线与预期相反）(`-axis-map-fix-v8`)

用户观察：自检实际动作顺序是"**右→左→下→上**"，而发出的命令是 `pitch, pitch, yaw, yaw`。
前两步同轴反向、动的是 yaw；后两步动的是 pitch —— 倒推出：

- `ttyS0`(U0, 驱动器 **ID=1**) 上挂的是 **pitch** 轴
- `ttyS2`(U2, **ID=2**) 上挂的是 **yaw** 轴

即"电机 ↔ 串口"的对应与最初设想**正好相反**；前几轮"yaw 不动"除了 pinmap 之外还叠了这一层。

**修法（只改代码、不动接线）**：把 yaw/pitch 的**端口 + 引脚 + 地址整体互换** ——
`YAW_DEV=/dev/ttyS2` + `YAW_PINS={B0,B1}` + `ADDR_YAW=2`；
`PITCH_DEV=/dev/ttyS0` + `PITCH_PINS={A28,A29}` + `ADDR_PITCH=1`。
另据实测把方向符号定为 **两轴正方向都是 CCW**（yaw: CCW=左/CW=右；pitch: CCW=上/CW=下）：
`YAW_POSITIVE_CCW=True`、`PITCH_POSITIVE_CCW=True`。
→ 自检序列变成 **pitch 上→下、yaw 左→右**（即"上、下、左、右"），符合要求。

**等效方案**（已写进 config/README 注释）：对调两根串口线 + 把驱动器 `ID_Addr` 设回
yaw=1 / pitch=2，则上面两组配置可改回原样；二者只需一处对上。

- `tools/uart_probe.py`、`README.md` 的接线表同步为实测映射；
- 门禁 **74 OK/0 FAIL**、`test_gimbal_aim` **PASS(20)**、target_api/laser 全过；
- `main.py` 与 `dist/` 均为 `2026-10-09-axis-map-fix-v8`。
