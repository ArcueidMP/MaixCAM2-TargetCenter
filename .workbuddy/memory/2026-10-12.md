# 2026-10-12 工作日志（25Efork）

## B 轨 v0.4.5：代码层掐断 MaixVision 图传 ⇒ 默认全帧

**触发**：用户贴板端日志 `[preview] show slow: p95=514ms`（恒定贴 505），确认 v0.4.4 的根因判定，
并要求「要全帧显示」。用户追问「不用 show 也能实现图传吧？之前根本不会」。

**源码级结论（MaixCDK，已抓源核对）**：
- `maixvision_mode()`（`components/vision/src/maix_image_trans.cpp`）实现就是
  `getenv("MAIXVISION") == "1"`。
- 图传通道 `img_trans` 在 **`Display()` 构造时**按 `maixvision_mode()` 创建一次
  （`maix_display.cpp`：`if(!img_trans && maixvision_mode()) img_trans = new ImageTrans(...)`）。
- `show()`（L190）与 `display.send_to_maixvision()`（L379-389，独立 API、不画本地屏）**首件事都是**
  `img_trans->send_image()` ⇒ **换 API 不能绕开 500ms 忙等**；唯一出路是**建 Display 前让 MAIXVISION≠1**。
- 建好再改环境变量无效（img_trans 已存在）。

**改法**：
- `config.py` 新增 `DISABLE_MAIXVISION_STREAM = True`（默认）。
- `main.py` 新增 `_apply_maixvision_stream_policy(cfg)`，在 `main()` **最前面**（建 Display 之前）调用：
  `os.environ["MAIXVISION"] = "0"`（os.environ 赋值 = putenv，C 侧 getenv 随即生效），并打印一行说明。
- `_Preview` 启动打印加 `maixvision=on/off` 字段；探针对策改为①保持开关 True ②设备本地启动 ③让预览真连上；
  `warn_slow_once` 文案同步。
- `tools/test_runtime_performance.py` 新增 `test_maixvision_stream_policy`（默认置 0 / 显式 False 保持 1 / 非 MaixVision 模式不动）。
- `BUILD_ID` → `2026-10-11-maixvision-off-v0.4.5`；`app.yaml` → `0.4.5`；重建 dist；README 加 v0.4.5 节。

**验证**：门禁 `OK=72 WARN=2 FAIL=0`；`build_single --check/--smoke` 通过；回归全绿
（runtime 8 项含新用例、main_self_test、performance、target_api、laser、gimbal_aim）。
开关冒烟：`MAIXVISION=1` 环境下调用后变 `0`，返回 True。

**代价（需知）**：MaixVision **画面预览面板**将无图（终端日志照常）。要看预览则
`DISABLE_MAIXVISION_STREAM=False` 且确保预览已连上。从设备本地启动应用时本无图传，开关无副作用。
