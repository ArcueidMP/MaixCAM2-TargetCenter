## ★ 本轮的核心推导：`dx/dy` → `dir` 字节（文档 §7.2）

相机随云台转 ⇒ 云台向右 → 靶在图像里左移（`Δu_靶 = −k·Δ右`）；
云台抬头 → 靶在图像里下移（`Δv_靶 = +k·Δ仰`）；
目标 `Δu_靶 = −dx`、`Δv_靶 = −dy` ⇒ `Δ右 = dx/k`、`Δ仰 = −dy/k`；
再代入用户给的两条转向定义 ⇒

**两轴统一：`dx>0` → 1 号机 CCW(`0x01`)；`dy>0` → 2 号机 CCW(`0x01`)；负值一律 CW(`0x00`)。**
（不需要任何隐藏负号；实测反了只改 `DIR_SIGN_*` 为 −1。）

## 查证到的 ZDT（Emm_V5.0）协议事实（文档 §6，官方说明书 Rev1.3 + 开源实现交叉核对）

- 帧 = `地址 + 功能码 + 数据 + 校验`；`Checksum=0x6B` 时校验字节**就是固定 0x6B**；**多字节参数大端**
- `0xF3` 使能 `addr F3 AB en sync 6B`（官网示例 `01 F3 AB 01 00 6B`）
- `0xF6` 速度 `addr F6 dir spd(2, RPM) acc sync 6B`（示例 `01 F6 01 05 DC 0A 00 6B`）
- `0xFD` 位置 `addr FD dir spd(2) acc pulses(4) mode sync 6B`（示例 `... 00 00 00 7D 00 00 00 6B`）
- `0xFE` 立即停止 `addr FE 98 sync 6B`；`0xFF` 多机同步 `addr FF 66 6B`
- `dir`：`0x00`=CW、`0x01`=CCW；**16 细分下 3200 脉冲 = 1 圈**
- **`acc = 0` = 不做曲线加减速**（非 0 时数值越大越快：每个 +1RPM 间隔 `(256−acc)×50µs`）
  → **增量闭环必须 `acc=0`**，否则爬速要几秒
- 返回帧：`02` 成功 / `E2` = 电机没使能或堵转保护 / `00 EE` 错误命令；`Response` 菜单决定回不回确认帧
- 上电前必须菜单设定：`P_Serial=UART_FUN`、`UartBaud=115200`、`ID_Addr=1/2`、`Checksum=0x6B`、
  `MStep`、`Response`、**`Cal`（编码器校准，空载做）**

## 另外两条新查证的引脚事实（写进文档 §3.2）

- **MaixCAM2 的 SPI1 不可用**：`SPI1_CS0` 在 `A2` 上，而出厂为防插错**把 A2 物理堵住**
  → 与 3507 的 SPI 只能用 **SPI2：B18=MOSI / B19=MISO / B20=SCK / B21=CS1**（同在左侧 2×6P 排针）
- B 轨 `config.py` 的 `UART_PORT = "/dev/ttyS0"` **是错的**（那是系统日志口）→ 必须改成 ttyS1/ttyS2

## 两个会让闭环起不来的前置问题（文档 §5.1，P0/P1 前必须解决）

1. **光斑极性未验证**：`LaserSpotDetector` 只认**亮斑**（`aiming.py:52` 的 `residual >= LASER_MIN_CONTRAST`、
   `:76-78` 的 `peak − ring`），而 405nm 打在**紫外感光纸**上的痕迹**可能是暗斑**（硅基 CMOS 对 405nm QE 低）
   → 需实测；若为暗斑要给检测器加 `LASER_POLARITY="dark"` 分支（两处不等号反向）。
2. **光斑 ROI 只有 ±32px**（`LASER_SEARCH_RADIUS`）→ 大偏差时检不到光斑 → 粗瞄必须用
   `LASER_MODE="fixed"` 的固定参考点，`|e|` 收到 <24px 再切 `detect`；
   且 `LASER_REFERENCE_SIZE` 应直接改成 `(640,480)`、`LASER_PIXEL` 填处理图像素，消除一次缩放换算。

## 控制方案定稿（文档 §7）

- **主方案：相对位置模式（`0xFD`，mode=0）+ 增量比例律**
  `ΔP = round(gain · |e| · PULSE_PER_PX)`，`gain` 粗瞄 0.9 / 精瞄 0.5，**单帧限幅 ≈10° 云台角**；
  不需要零点、丢帧下一帧视觉自动补、与驱动器内部累计语义无关。
- **`PULSE_PER_PX` 必须实测，不要数齿数**：走 2000 脉冲量 `Δdx` → 一次性吸收齿轮比/细分/焦距/安装角；
  同时算交叉项 `Δdy/Δdx`（>0.25 说明相机横滚没装正）。
- **死区 ≥ 1.5 × 回差**：`B_px = 云台回差(°) × 9.7`，**回差 1° 就吃掉整个 7.4px 预算**；
  减速比越大负载侧回差越小（电机侧 / i）；极小死区必然在回差带里抖。
- 状态机：`BOOT`(只使能) → `COARSE` → `FINE` → `SETTLE` → `HOLD`(aim_valid=False 不发指令) → `SCAN` → `FAULT`(发 0xFE 停)。

  含"符号反了会发散"的用例）。

### 两个踩坑记录（会再遇到）

1. **★ SysConfig 1.28.0 与 MSPM0 SDK 2.02 器件数据不匹配**：PB22 / PB26 / PB27（板载 RGB LED 三个通道）
   会被解析成**不存在**的 `GPIOC.x`（MSPM0G350x 只有 GPIOA/GPIOB）→ 生成代码报
   `use of undeclared identifier 'GPIOC'`，**SDK 自带例程也踩这个坑**。
   `IOMUX` 的 pinCMx 是对的，错的只有端口字母+位号。
   实测：PA0/PA1/PB0/PB6/PB7/PB13/PB16/PB23 正确；PB20/PB24/PB25→错成 `GPIOA.0`；PB21/PB22→`GPIOC.2`；PB26/PB27→`GPIOC.1`。
   → 本工程 syscfg **只配时钟**，LED 引脚在 C 里手写（`GPIOB` + `DL_GPIO_PIN_26` + `IOMUX_PINCM57`）。
   另：`GPIO.associatedPins[n].assignedPin = "22"` 这种写法会被解析成"端口C/引脚2"，**只能**用 `pin.$assign = "PBxx"`。
2. **写给 cmd 的 `.bat` 必须纯 ASCII**（UTF-8 中文注释在 GBK 控制台下会把命令行拆坏，报一堆
   `不是内部或外部命令`）；且在 `if (...) ( ... )` 代码块内的 echo **不能出现裸右括号**，会提前结束块。

### LP-MSPM0G3507 板载 LED 引脚（User's Guide SLAU873 表 2-1）

LED1（红，单色）= **PA0**；RGB LED2：蓝 = **PB22**、红 = **PB26**、绿 = **PB27**；RGB 为共阴（置 1 点亮）。
