## 2026-10-06（下午）· B 轨：MaixCAM2 串口直控云台需求文档

**用户目标**：不再"只发坐标给下位机"，而是 **MaixCAM2 自己当瞄准模块主控**，用 **UART1 + UART2** 直接驱动云台电机，
把激光光斑压到黑框中心。**本轮只写文档，未改任何代码。**

**产出**：`maixcam2_rect_center/MaixCAM2串口直控云台需求文档.md`（858 行，LF，已被 `app.yaml` 的 `*.md` 排除）。

### 本轮查证的硬事实（可复用，别再重新查）

- **MaixCAM2 串口映射**（Wiki UART 页 + 板卡引脚图 v1.0 + MaixCDK `maix_pinmap.cpp` 三处交叉验证）：
  `ttyS0`=UART0(A28/A29，系统终端，禁用)、**`ttyS1`=UART1(A30=TX / A31=RX)**、
  **`ttyS2`=UART2(B0=TX / B1=RX，专用引脚免 pinmap)**、`ttyS3`=UART3(B2/B3)、`ttyS4`=UART4(A21/A22，1.25mm 6P 座)。
  ⚠ Wiki 的 UART 表格里 MaixCAM2 的 UART1 引脚栏是空的，**只有引脚图与 MaixCDK 源码给出 A30/A31** → 上板必须
  `pinmap.get_pin_function("A30")` 现场核实。
- **A30 四功能**：`GPIOA30 / PWM6 / UART1_TX / SPI2_CS3` → 用了 UART1 就放掉 PWM6（影响"改用 PWM 舵机"的退路）。
- 引脚图另给出：`A2` 出厂被**防呆堵住不可用**；`A6`=状态灯、`B25`=照明 LED、`D2`=用户按键，均别占。
- **IO 一律 3.3V**；板上 5V 引脚在**仅电池供电时只有 3.7~4.2V**（不能给舵机总线供电）。
- 波特率官方推荐 **115200（8N1）**；UART0 的 TX 是启动模式脚，**上电被拉低会开不了机**。
- API 要点：`available(timeout)` 非阻塞查数据；`read(-1,0)` 非阻塞取缓冲区；**`set_received_callback` 与 `read` 不能混用**；
  回调在**另一线程**执行。主循环只该用 `available()`+`read()`。
- **普通舵机是 PWM 不是串口**；能串口控的只有总线舵机 / 串口闭环步进伺服 / 串口舵机。
  总线舵机是**单线半双工** → **TX 直接短接 RX 有推挽短路风险**，正解：TX 串 1kΩ 进总线、RX 直连、共地（或专用收发器）。

### 本轮定下的设计结论（下一轮直接照做）

1. **控制范式 = 图像伺服**：前提是相机与激光同平台共轴 → "靶心保持在图像中心" ⟺ "激光指着靶心"，
   于是**不需要知道小车位置、不需要解算云台-车体关系**，这也正是"移动中瞄准"能成立的基础。
2. **★ k = fx·π/180 ≈ 9.7 px/deg（fx≈554@640宽/60°FOV），且对"相机随云台动"的系统与距离无关** ——
   增益只需标定一次；与"2cm@1.5m ≈ 7.4px"互相印证：**驱动精度 2~3px 就够**。
3. **误差预算结论：本题瓶颈不在视觉**（B 轨 0.803px ≈ 0.22cm@1.5m，离 2cm 有近 10 倍余量），
   而在**链路协议/延迟 + 机械回差 + 激光-相机视差标定**。别再去抠检测算法。
4. **视差模型 `Δu = a + f·b/Z`**：`a` 是角偏差（与距离无关）、`b` 是横向基线（∝1/Z）。
   **两个距离点各测一次即可解出两者** → 运行时把靶心驱到 `(cx + a + b/Z, cy + a_v + b_v/Z)` 而不是图像中心。
5. **闭环必须用 `raw_u/raw_v`**：`CENTER_ALPHA=0.70` 的一阶低通等效滞后 0.83 帧 ≈ 28ms，
   移动中 90°/s 底盘 → 2.5° ≈ **6.6cm@1.5m**，直接超差。**闭环只用视觉反馈不满足发挥部分，必须前馈（这就是 UART1 留给底盘的理由）**。
6. **协议弃用 `@[u,v]%`**：现状 6 个问题（丢亚像素、无校验、无序号、无定长、无接收、无失联保护）。
   改为上行 **15B 定长**（双帧头 + cmd + seq + flags + conf + **u_x10/v_x10 定点** + z_mm + t_ms + CRC8）、
   下行 10B 状态（角度/到位/限位/故障）。15B@115200 = 1.30ms，30Hz 占带宽 3.9%，无压力。
7. **距离估计免标定法**：`Z = Z0 · w_px0 / w_px`（外框像素宽度 ∝ 1/Z），不用先标焦距。
8. 代码分层：新增 `vision/gimbal_link.py`（协议+双串口+pinmap）、`vision/aimer.py`（**纯 Python 无 maix**，可离线仿真）、
   `tools/test_aim.py`（假 UART/电机做闭环离线仿真）；`main.py` 只接三处（pinmap 初始化 / publish+poll / `[perf]` 加 `rx`+`aim`）。
   → 新模块**禁止顶层 import maix**（否则 PC 测试挂 + `check_app.py` C5 判 FAIL）；新增两 py 后**应用包 6→8 文件**，必须核清单。
